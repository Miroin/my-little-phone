# 小手叽 v2 完成度

更新时间：2026-11-08

## 已有真实实现

- React + TypeScript + Vite 前端，可独立构建并发布预览。
- FastAPI 后端骨架，DeepSeek Key 只从服务端环境变量读取。
- 基础聊天消息持久化和最近 24 条上下文。
- 返回按钮按页面历史回到上一级。
- 七层记忆：人格、关系、用户、事件、感受、计划、互动样本。
- 记忆原文证据、哈希去重、状态管理、使用记录和用户反馈表。
- 不依赖向量服务的关键词降级检索。
- ChatGPT `conversations.json` 上传、双方识别、时间和会话解析。
- 文件指纹、重复批次恢复、分段提交和断点继续。
- 原始会话与消息分页读取。
- 免费本地候选初筛、每个会话数量限制、每页 20 条、默认不选。
- 候选人工确认后写入长期记忆，重复内容自动跳过。
- 后端记忆与迁移冒烟测试。

## 底层已写，尚未部署

- v2 后端全部接口。
- SQLite 持久数据文件。
- 前端读取真实聊天、记忆、迁移批次与候选的 API 调用。
- DeepSeek 聊天代理。

当前 GitHub Pages 只托管前端，因此线上预览会显示“预览模式”。需要部署持续运行的后端并配置数据库后，这些功能才能在手机上真正读写。

## 部分实现

- **聊天**：文字聊天接口已写；流式输出、重试队列、场景判断、完整人格分层提示词和正式测试集未完成。
- **记忆**：分层存储、证据和关键词检索已写；向量检索、冲突合并、衰减/归档、可视化编辑和备份恢复未完成。
- **历史迁移**：原文迁移和本地初筛已写；DeepSeek 精细提取、任务暂停/恢复控制、候选编辑和完整性报告未完成。
- **通话数据**：已有 calls 表和统一消息字段；实时通话链路、通话逐轮落库及挂断摘要未完成。
- **人物资料**：已有展示页；陈钰/沈砚切换编辑、六大分类和导入管理未接后端。

## 推荐顺序

1. 完成 DeepSeek 精细提取、候选合并和迁移完整性报告。
2. 部署持续运行的后端与持久数据库，让 v2 从预览变成可用系统。
3. 接入完整人格/关系/互动样本检索并跑固定聊天测试集。
4. 完成真实语音消息和统一音频存储。
5. 建立实时通话流、逐轮转写、通话记忆和挂断记录。
6. 建主动陪伴调度、推送和主动来电。
7. 加 PWA，再用 Capacitor 封装 App 与系统通话能力。
8. 最后补齐小家、音乐、相册、主题等生活模块。
