# Phase 3 — MEMORY 与 JOURNAL

完成日期：2026-11-16

## MEMORY · 私人记忆收藏室

- 收藏入口改为木质抽屉式分类索引，不再沿用普通圆角卡片网格。
- 人格、关系、用户、事件、感受、约定和互动样本均显示真实数量。
- 记忆内容改为纸质收藏卡展示。
- 编辑状态改为档案编辑纸张，保留分类、摘要、正文和重要度调整。
- 原文证据改为收藏卡中的引用纸条。
- 保留整理最近聊天、确认准确、归档、恢复、候选确认、永久删除和分页。
- 后端未连接时继续显示预览状态，不伪造记忆。

## JOURNAL · 私人日记本

- 新建区改为带横线的纸质书写页。
- 日记阅读区改为独立纸页，保留日期、标题、正文和删除。
- 增加真实空状态，不放置示例日记。
- 保留真实新建、读取、删除和备份数据链路。

## 验证

- TypeScript 检查通过。
- Vite 生产构建通过。
- 已实际打开 MEMORY 与 JOURNAL 检查桌面视口。
- 已增加手机窄屏规则。

## 当前数据能力限制

- 日记后端目前没有更新接口，因此没有伪造“编辑保存”。
- 日记记录目前没有照片关联字段；图片仍由真实相册功能独立保存。后续需要先扩展数据结构和备份格式，才能加入真正的日记插图。
