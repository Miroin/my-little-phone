- 顶部保留真实日期、时间、返回和背包入口。

- 互动提示改为像素游戏对话框。
- 场景标签区分一楼、二楼和庭院。

- 沈砚保持在可见且可互动的位置，不再与角色或宠物叠成方块。

- 一楼、二楼、庭院切换。
- 沈砚互动并记录桥接事件。
- 阿比和伯恩山互动，真实修改心情与饥饿。
