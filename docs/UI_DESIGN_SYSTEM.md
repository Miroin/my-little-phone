# Our Little Universe — Phase 1 基础设计系统

## 视觉比例

- 60% 月光极简：月光白、细线、低对比阴影、清楚的内容层级。
- 30% 艺术编辑：衬线标题、中英文栏目标签、不对称构图。
- 10% 复古材质：纸张边缘、奶油色、少量木色和香槟金。

材质是局部空间语言，不作为所有内容的统一卡片外壳。

## 基础变量

变量集中在 `src/design-system.css`：

- 色彩：`--ui-moon`、`--ui-lavender-*`、`--ui-cream`、`--ui-paper`、`--ui-blue`、`--ui-gold`、`--ui-wood`。
- 语义状态：`--ui-success`、`--ui-warning`、`--ui-danger`、`--ui-info`。
- 字体：展示、正文、等宽三套字体栈。
- 字号：`xs` 至 `2xl` 六级。
- 间距：4px 基准，1 至 12 八级。
- 圆角：2、6、12、20px 和完整圆形；大圆角只用于真正的浮层或柔软控件。
- 阴影：发丝线、纸张、浮层三级。
- 动效：140、240、420ms 三级，并支持减少动态效果。
- 触摸：交互控件最小 44px。

旧页面使用的变量暂时通过兼容别名映射到新变量，后续逐个应用迁移，不进行一次性破坏性替换。

## 基础组件

`src/ui/Primitives.tsx` 提供：

- `Button`：primary、secondary、quiet、danger。
- `Field`、`Input`、`Textarea`、`Select`。
- `Status`：info、success、warning、error，错误状态使用 `role=alert`。
- `Sheet`：移动端抽屉/弹层基础结构，包含标题、关闭按钮和无障碍语义。

这些组件只解决输入、操作、状态与弹层，不提供统一页面模板。

## 使用规则

- 应用页面可以共享变量与基础控件，不共享内容布局。
- MEMORY、JOURNAL、MUSIC、CINEMA、CALENDAR、CHAT、HOME 各自拥有布局样式。
- 不用阴影、渐变和圆角替代内容层级。
- 纸张、玻璃、木色仅在能表达空间意义时使用。
- 所有加载、成功、错误状态必须占据稳定位置，避免页面跳动。
- 对话框与抽屉必须有清楚标题、关闭方式、键盘焦点和触摸区域。
- 游戏继续使用独立像素 UI，不复用手机应用的纸张或玻璃组件。
