# Phase 4 — MUSIC 与 CINEMA

完成日期：2026-11-16

## MUSIC · 私人唱片角

- 唱片机成为页面主视觉，棕色设备台改为深夜炭紫与月光紫。
- 推荐、搜索、榜单和听歌报告保留独立入口。
- 搜索结果与排行榜改为唱片架目录式排列。
- 保留 QQ 音乐真实接口状态、真实搜索与跳转播放。
- 未连接 QQ 音乐时显示明确空状态，不生成假歌曲。
- 听歌报告继续读取真实接口数据。

## CINEMA · 私人影院

- 页面改为深色私人放映室，提升文字和输入框对比度。
- 新增电影区域改为放映策展台。
- 片库中的真实记录以电影海报比例陈列。
- 保留电影名称、观看状态、评分或短评、新增与删除。
- 空片库显示幕布空状态，不生成假电影或假播放器。

## 验证

- TypeScript 检查通过。
- Vite 生产构建通过。
- 已在实际浏览器中打开 MUSIC 与 CINEMA 检查布局和空状态。
- 手机窄屏和桌面宽屏均有对应排列规则。

## 当前数据能力限制

- QQ 音乐连接前无法展示真实曲库，页面不会使用示例歌曲填充。
- 电影数据目前只有标题、文本记录与创建时间，没有独立海报上传、数值评分、观看状态字段或更新接口；本阶段保留真实数据能力，没有伪造详情保存。
